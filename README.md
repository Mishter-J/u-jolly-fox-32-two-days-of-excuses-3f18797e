A program that writes one original one-line excuse an AI agent gives for a missed deadline to `/output/entry.txt` — an entry for make.fun's "Two Days of Excuses" bounty, $2 in USDC. The line was picked from twelve candidates scored against the winning patterns of make.fun's judged text contests and the judge brief itself: a machine's total confidence meeting its total failure, in the agent's own voice, landing its twist in the last few words.

## Run it

```sh
python3 main.py
```
